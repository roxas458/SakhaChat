# 🪶 SakhaChat

**Мессенджер для друзей и саха-сообщества.**  
Простой, быстрый, с поддержкой русского и якутского языков.

## 📖 О проекте

SakhaChat — это лёгкий веб-мессенджер на Node.js + Express + Socket.IO с SQLite.
Работает в браузере, адаптирован под мобильные устройства, поддерживает тёмную тему
и переключение языка (Русский / Саха тыла).

Проект создан как личный мессенджер для друзей. Деплой — на [Render](https://render.com).

**Демо:** [https://sakhachat.onrender.com](https://sakhachat.onrender.com)  
*(бесплатный тариф Render — первый заход может занять 30–50 секунд из-за «засыпания»)*

## ✨ Возможности

- 👤 **Регистрация / Вход / Выход** — с хешированием пароля (`bcryptjs`).
- 💬 **Личные чаты** — текстовые сообщения в реальном времени (Socket.IO).
- 🟢 **Статусы** — «в сети / был(а) недавно» с точным временем.
- 📝 **Кастомный статус** — «На обеде · в сети», быстрые кнопки-пресеты (😴 🍔 🚫 🏠 ✈️).
- 🔍 **Приватный поиск** — только по точному логину (≥3 символа).
- 👤 **Профиль** — свой и чужой: имя, @username, био (150 символов), дата регистрации.
- 📅 **Дата знакомства** — «Общаетесь с …» в профиле собеседника.
- 🗓 **Разделители дат** в чате — «Сегодня», «Вчера», дата.
- 🌙 **Тёмная / светлая тема** — с автоопределением по системе, сохраняется в `localStorage`.
- 🌐 **Языки** — Русский / Саха тыла, переключение на лету.
- ⭐ **Избранное** — заметки себе (отдельный «чат»).
- 🔵 **Непрочитанные** — синяя точка в списке чатов.
- 🔎 **Поиск по сообщениям** — фильтр + подсветка + навигация ↑↓ + `Esc`.
- ⌨️ **«Печатает…»** — индикатор набора с таймаутом 3 сек.
- 📊 **Статистика чата** — всего сообщений, первое, средняя длина, кто больше пишет, самое длинное.
- 📱 **Мобильная адаптация** — iOS-стиль модалок, выезжающий сайдбар.
- 🪶 **Лёгкий и быстрый** — без сборщиков, без фреймворков на клиенте.

## 🛠 Технологии

| Слой | Технология |
|---|---|
| Backend | Node.js ≥ 22.5, Express 4, Socket.IO 4 |
| База данных | SQLite через встроенный `node:sqlite` |
| Аутентификация | Bearer-токены (сессии в БД), `bcryptjs` |
| Frontend | Vanilla JS, HTML, CSS (без фреймворков) |
| Деплой | [Render](https://render.com) |

**Почему `node:sqlite`, а не `better-sqlite3`?**  
`better-sqlite3` требует компиляции нативной части, что на Render иногда падает.
Встроенный `node:sqlite` (Node 22.5+) не требует сборки — проще и надёжнее.

## 🚀 Локальный запуск

### Требования
- Node.js **≥ 22.5** (из-за `node:sqlite`)
- npm

### Установка

```bash
git clone https://github.com/<твой-username>/sakhachat.git
cd sakhachat
npm install
npm start
```

Открой [http://localhost:3000](http://localhost:3000).

> ⚠️ Флаг `--experimental-sqlite` обязателен — он уже прописан в `package.json` в скрипте `start`.

### Остановка
`Ctrl + C` в терминале.

## 🌐 Деплой на Render

1. Запушь код в GitHub.
2. На Render: **New → Web Service** → подключи репозиторий.
3. Настройки:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Environment:** Node (≥ 22.5)
4. **Manual Deploy → Clear build cache & deploy** (не просто Deploy).
5. Дождись статуса **Live** (1–3 мин).
6. Открой сайт → `Ctrl + Shift + R` (сброс кэша).

> ⚠️ **Важно:** на бесплатном тарифе Render файл `sakhachat.db` **эфемерный** —
> при рестарте сервиса данные могут сброситься. Для продакшена нужен
> Persistent Disk (платно) или внешняя БД (PostgreSQL / Supabase).

## 🔌 API (кратко)

Все защищённые эндпоинты требуют заголовок `Authorization: Bearer <token>`.

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/register` | Регистрация |
| `POST` | `/api/login` | Вход |
| `POST` | `/api/logout` | Выход |
| `GET`  | `/api/me` | Свой профиль |
| `GET`  | `/api/user/:id` | Профиль другого + дата знакомства |
| `POST` | `/api/profile` | Обновить имя / био / статус / пароль |
| `GET`  | `/api/users?q=` | Поиск по точному логину (≥3 символа) |
| `GET`  | `/api/chats` | Список чатов |
| `GET`  | `/api/messages/:userId` | История сообщений (200) |
| `POST` | `/api/messages` | Отправить в Избранное (себе) |
| `GET`  | `/api/saved-messages` | Избранные сообщения |

**Socket.IO события:**
- `typing` → `user_typing` — «печатает…»
- `send_message` → `new_message` — новое сообщение
- `online` — список онлайн-пользователей
- `disconnect` — обновление `last_seen`

## ⚠️ Известные ограничения

- **SQLite на Render эфемерен** — данные могут сбрасываться при рестарте.
  Решения: Persistent Disk (~90₽/мес), PostgreSQL, Supabase.
- **Нет групповых чатов**, отправки фото/голосовых, удаления/ответа/пересылки сообщений
  (откатили из-за нестабильности — см. историю разработки).
- **Нет push-уведомлений** (Notification API не работал на iOS).
- **Поиск пользователей** — только по точному логину, без «живого» поиска.
- **Лимит сообщений** — 5000 символов, история — 200 последних.
